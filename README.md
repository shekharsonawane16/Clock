# Digital Clock

A responsive digital clock built using HTML, CSS, and JavaScript that displays the current time and date in a clean, modern interface.

---

## 🔗 Live Demo

👉 [Open Digital Clock](https://shekharsonawane16.github.io/Clock)

---

## ✨ Features

- Real-time digital clock
- 12-hour time format
- AM/PM indicator
- Live date and day display
- Updates every second
- Responsive design
- Modern user interface
- Glowing digital clock effect
- PWA-ready structure

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web App Manifest

---

## 📚 Concepts Practiced

- JavaScript Date Object
- DOM Manipulation
- `setInterval()`
- JavaScript Functions
- Conditional Logic
- String Formatting
- `toLocaleDateString()`
- Responsive Web Design
- CSS Flexbox
- CSS Gradients
- CSS Animations and Effects
